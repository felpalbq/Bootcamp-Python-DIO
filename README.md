# 🚀 Branch: Criação – Sistema Bancário

Esta branch contém a **primeira versão do sistema bancário**, focando na **criação** de funcionalidades essenciais: **saldo**, **depósitos**, **saques** e **extrato**. O sistema foi desenvolvido utilizando conceitos de **Python** como manipulação de **strings**, **operadores**, **condicionais** e **laços de repetição**.

---

## 🧩 Funcionalidades Implementadas

As funcionalidades implementadas até o momento são:

- **Saldo**: O saldo da conta é exibido quando solicitado.
- **Depósito**: O valor informado pelo usuário é adicionado ao saldo da conta.
- **Saque**: O usuário pode realizar saques, com limite de R$ 500 por saque e limite de 3 saques diários.
- **Extrato**: O histórico de operações (depósitos e saques) é mantido e pode ser visualizado.

---

## 🧑‍💻 Estrutura do Sistema

1. **`saldo`**: Variável que armazena o saldo atual da conta.
2. **`operacoes`**: Lista que mantém o histórico de operações realizadas (depósitos, saques, consultas de saldo).
3. **`LIMITE_SAQUES`**: Limite de saques diários (máximo de 3).
4. **`LIMITE_SAQUE`**: Limite de saque individual (R$ 500).
5. **`numero_saques`**: Contador de saques realizados.

## 📝 Como Testar o Sistema

    ```bash
    cd Bootcamp-Python-DIO
    ```

2. **Acesse a branch `criação`**:

    ```bash
    git checkout criação
    ```

    ```bash

    ```
